# Bili

Windows 多平台下载工具，v1.1.0 为 2026-10-15 封板正式版。

## 下载与运行

从 [v1.1.0 Release](https://github.com/Hikaru232572/bilibili-downloader-gui/releases/tag/v1.1.0) 下载 **Bili-v1.1.0-windows-x64.zip**，完整解压后运行 `BilibiliDownloader.exe`。无需安装 Python 或下载工具。保留同目录的 `_internal` 和许可文件。支持 Windows 10/11 x64。

## 功能与使用

- 粘贴 B站、抖音、小红书单个作品的链接或分享文案；B站也支持 BV 号，多链接先选择作品。
- B站：选择画质保存视频，或保存 MP3/WAV，支持作品已有原生字幕。
- 抖音：视频/音频独立选择，可同时保存；音频默认保留原始编码，也可转为 MP3/WAV；支持静态图文。
- 小红书：静态图文、小图/源图预览、按图选择与原尺寸查看。
- FIFO 队列，任务卡片、取消/继续/重试、文件校验、成品复用与同名避让。说明见 [下载任务](docs/download-tasks.md)。
- 进行中与最近完成分开，完成任务短暂保留在进行中，完成记录保留 7 天。移除记录不删除文件。
- 三平台分别配置游客、浏览器或 Cookie 文件认证；退出/后台托管与手动恢复任务。
- 保留原有背景、图标和手绘风格，解析结果原位展开；页面切换保留状态，设置草稿可撤销，底部跨页面显示真实任务状态。

需要登录时，在设置中选择对应平台与认证来源。浏览器读取可能受加密或锁库影响，可以使用 Netscape 格式 cookies.txt。Cookie 相当于登录凭据，不要分享或提交 Git。配置、任务、预览默认保存在 `%LOCALAPPDATA%\Bili`，下载文件保存在所选目录。清除认证只解除引用，不删除外部文件或退出浏览器账号。

设置修改只在点击保存后生效；返回和跨页保留未保存草稿，撤销恢复已保存值。小窗口内容可滚动，输入框、页脚和保存操作保持可用。

## 支持边界与验证范围

- 动态图文暂不支持；识别到动态项目时仅保存可得静态图并提示。小红书普通视频笔记不在本版范围。
- 不自动采集主页、合集或收藏；不承诺未知资源的画质或水印状态。
- 平台接口、登录权限和网络可能变化；失败任务会保留原因，可重新尝试。
- 真实字幕失败后的成功补入、系统通知实际显示/点击、独立干净机器全流程仍未完成全面验证，不能把本机回归替代为这些验收。
- 程序未商业代码签名。可使用 Release 的 SHA256SUMS.txt 校验下载文件。
